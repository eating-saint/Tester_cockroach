# 用户部署声明

本项目是一个**在你自己电脑上运行**的网页自动化工具：程序负责打开网页、点击、输入、滚动；本机的小视觉模型只负责"在截图上选编号"；
你用积木拼出的**任务书**（`tasks/*.yaml`）决定要做什么。部署前请读完本文。

## 1. 运行环境

| 项 | 要求 |
|---|---|
| 系统 | Windows 10 / 11（桌面驱动只支持 Windows；CDP / Playwright 驱动理论上跨平台，未验收） |
| 浏览器 | Google Chrome；用桌面驱动时 Chrome 必须是**默认浏览器** |
| 视觉模型 | [Ollama](https://ollama.com) + 一个多模态模型，默认 `qwen3.5:4b`；可在 `config.yaml` 的 `vlm:` 段换成你自己的模型服务 |
| 显卡 | 建议 8 GB 显存（4b 模型可全部放进显卡）；没有独显也能跑，只是每次选号慢很多 |
| 内存 / 磁盘 | 16 GB 内存；首次部署约 7 GB 磁盘，见下表 |
| 源码运行 | Python 3.11+（开发用 3.12） |

## 2. 体积预估（2026-11 实测）

| 组成 | 大小 | 说明 |
|---|---|---|
| 本程序（PyInstaller onedir，含 Playwright 驱动） | 约 180 MB，压缩后约 70 MB | 其中 Playwright 驱动约 100 MB |
| 本程序（不带 Playwright，只用 CDP / 桌面驱动） | 约 80 MB，压缩后约 30 MB | 推荐的发行形态 |
| Ollama 程序 | 约 3.2 GB（安装后） | 大部分是 CUDA / ROCm 显卡库 |
| 模型 `qwen3.5:4b` | 约 3.3 GB | `ollama pull qwen3.5:4b` |
| 每次运行的记录（`runs/`） | 每次约 4–30 MB | 截图为主；不会自动清理，可随时删 |

合计：首次部署约 **6.5–7 GB**，其中本程序只占 0.1–0.2 GB，其余是 Ollama 和模型。

> 打包注意：上一版打包产物里混进了 `data/profiles/`（浏览器用户目录，含 Cookie）和 `jedi`（开发环境带入），
> 发行前必须删掉 `data/profiles/` 并在 `packaging/panel.spec` 的 `excludes` 里加上 `jedi`、`IPython`。

## 3. 安装

```bash
pip install -e .[panel,desktop]          # 面板 + 桌面驱动；需要 Playwright 再加 ,pw
ollama pull qwen3.5:4b
setx OLLAMA_CONTEXT_LENGTH 16384         # 设完重启 Ollama
python -m panel                          # 打开控制面板（默认端口 8790）
python -m hands book tasks/ralphs_coupons.yaml --driver desktop   # 命令行直接跑一份任务书
```

打包版：解压后运行 `HandsPanel.exe`；数据（配置、任务书、运行记录）在程序旁边的 `data/` 里，升级只替换程序文件。

## 4. 数据与隐私

- **截图和页面内容不出本机**：视觉模型通过本机 Ollama 运行，程序不向任何第三方服务上传截图、页面或任务书。
- 桌面驱动在你**默认的 Chrome Profile** 里开一个新窗口，用的是你自己的登录状态和 Cookie；它能看到你在这些网站上能看到的一切
  （收货地址、账户名、购物车等），这些都会出现在 `runs/` 的截图和记录里。**分享运行记录或报告前请自己检查。**
- `runs/`、`logs/`、`profiles/`、`panel_devices.json` 都只在本机，已在 `.gitignore` 里，不要提交或上传。
- 平板远程默认关闭；开启公网隧道（cloudflared）后，持有配对链接的设备可以看到运行画面缩略图，用完请关闭。

## 5. 使用边界（程序强制执行的部分）

- **永远不往密码框输入**；遇到登录页、密码框、短信验证码、人机验证（CAPTCHA、"按住按钮"等）一律**暂停转人工**，
  不做任何规避或破解。
- **下单、支付类按钮和结算地址由兜底拦截硬拦**，所有决策方式都生效，不能整体关闭。
- 加入购物车、领券、收藏、写评价、预订、提交表单等账户动作**先问"允许一次 / 拒绝"**。
- 桌面驱动动的是**真实鼠标键盘**：运行时请别碰；一碰就暂停，停手 `desktop.idle_resume_s` 秒（默认 1 秒）后继续。
  鼠标速度、打字速度、暂停时长都在 `config.yaml` 的 `desktop:` 段。
- 对同一网站的访问有最小间隔（`min_interval_s`），任务书有次数上限，用满就停下等你决定。

## 6. 使用者责任

- 请遵守你访问的网站的服务条款和 robots 规则；有些网站禁止自动化访问，**被拦截时请不要尝试绕过**。
- 你对自己用本工具发起的操作负责（包括在已登录账户里的操作）。程序的拦截和确认是兜底，不是保证。
- 本项目按原样提供，不对因使用造成的账户限制、数据丢失或其他损失负责。
- 视觉模型会认错、读错：结果里的价格、评分、优惠信息请以网站页面为准。
